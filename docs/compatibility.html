Compatibility

Notes about bundlers, SSR, and runtime environment.

Browser / DOM required

goalcalendar is a DOM-based library. It uses document and directly manipulates elements. It is intended for browser usage.

SSR (Next.js / Remix / Nuxt)

Do not instantiate new Calendar(...) during server-side rendering. Create it only on the client (e.g. in useEffect). 

import { useEffect } from 'react'
import { Calendar } from 'goalcalendar'
import 'goalcalendar/style.css'

export default function Page() {
  useEffect(() => {
    new Calendar({ containerId: 'calendarContainer' })
  }, [])

  return <div id="calendarContainer" />
}

Bundlers

  • Vite: works (ESM import)
  • Webpack: works (ESM/CJS depending on config)
  • Node: not supported as a UI runtime (unless you provide a DOM like jsdom)

CSS

Remember to import goalcalendar/style.css (and optionally goalcalendar/modern.css) from your app.
