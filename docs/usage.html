goalcalendar – Usage (v1.0.1)

This page documents the current npm package API.

Install

npm install goalcalendar

Minimal (classic)

import { Calendar } from 'goalcalendar'
import 'goalcalendar/style.css'

new Calendar({
  containerId: 'calendarContainer',
  // defaults:
  // theme: 'classic'
  // size: 'large'
  // startOfWeek: 'Monday'
  // labelLength: 3
})

Modern theme

import { Calendar } from 'goalcalendar'
import 'goalcalendar/style.css'
import 'goalcalendar/modern.css'

new Calendar({
  containerId: 'calendarContainer',
  theme: 'modern',
})

Data API: setData

Recommended way to provide day items without calling legacy methods.

import { Calendar } from 'goalcalendar'
import 'goalcalendar/style.css'

const cal = new Calendar({ containerId: 'calendarContainer' })

cal.setData({
  '2026-01-01': [
    { text: 'Gym', complete: 1, goal: 1 },
    { text: 'Study', complete: 0, goal: 2 },
  ],
  '2026-01-02': [{ text: 'Read', complete: 1, goal: 2 }],
})

DayItem shape

  • text (string) – label/description
  • complete (number) – current amount (default 0)
  • goal (number) – target amount (default 0)

CSS customization

Water-fill vars

  • --goalcal-fill-color
  • --goalcal-fill-speed
  • --goalcal-fill-start
  • --goalcal-fill-end

Theme vars (recommended)

The library exposes --gcl-* variables on .cjslib-calendar to make theming easy (backgrounds, borders, text colors, etc.).
